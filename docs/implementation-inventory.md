# Implementation inventory

This inventory reflects the checked-out `dev` tree, including currently
uncommitted work. “Verified” means exercised by the stated local automated
checks; PostgreSQL was contacted only for designated local repository and
migration-test databases. No live Tremol or KRA system was contacted. The
repository does not retain primary response evidence for the previously
reported Zoho invoice request described below.

Latest reported local verification: full suite 67 files passed and 4 skipped
(865 tests passed, 17 skipped); PostgreSQL repository integration suites passed
15 tests; fresh-install migration assertions passed 2 tests and applied all 18
migrations on a newly created suffixed local database. `pnpm audit:deps`
reported no known vulnerabilities after SQL Server persistence support was
removed. These are local results, not customer acceptance; re-run checks for a
release. See the [office acceptance runbook](customer-office-acceptance-runbook.md).
